## 📌 О задаче

**Цель:** бинарная классификация сессии пользователя на сайте e-commerce — завершится ли она покупкой (`Revenue = 1`) или нет (`Revenue = 0`).

**Ключевые особенности:**

- Сильный дисбаланс классов: **84.5% / 15.5%**.
- Основная метрика — **ROC-AUC** (устойчива к дисбалансу), дополнительно — **F1**.
- Бизнес-ценность: оптимизация рекламного бюджета, персонализация офферов, выявление проблем UX.

**Что сделано в модуле:**

- Создано **12 инженерных признаков** (суммы, средние, отношения, бинарные флаги, сезонность).
- Обучены **4 ансамблевые модели**: Random Forest, XGBoost, LightGBM, CatBoost.
- Проведён **тюнинг через Optuna** (30 испытаний, StratifiedKFold 5).
- Интерпретация через **SHAP** (summary, bar, waterfall, dependence).
- Модели и метаданные сохранены в `models/`, лучшая модель загружается из репозитория через `BASE_URL`.

## 📊 Результаты

### Сравнение базовых моделей (test set, 20%)

| Модель | Accuracy | Precision | Recall | F1 | ROC-AUC | Время обучения |
|---|---|---|---|---|---|---|
| Random Forest | 0.8710 | 0.5586 | 0.7984 | 0.6573 | 0.9247 | 0.400 сек |
| XGBoost | 0.8824 | 0.6000 | 0.7225 | 0.6556 | 0.9222 | 0.279 сек |
| LightGBM | 0.8731 | 0.5662 | 0.7723 | 0.6534 | 0.9255 | 0.171 сек |
| CatBoost | 0.8702 | 0.5587 | 0.7723 | 0.6484 | 0.9260 | 1.031 сек |
| **LightGBM (Optuna)** | **0.8798** | **0.5851** | **0.7906** | **0.6722** | **0.9327** | — |

**Лучшая модель:** LightGBM после Optuna — **ROC-AUC = 0.9327** (прирост **+0.72%** к baseline).

**Топ-5 признаков (LightGBM feature importance):**

1. `ProductRelated_Duration` — время на товарных страницах
2. `ProductRelated` — число товарных страниц
3. `ExitRates` — показатель выходов
4. `PageValues` — ценность страниц
5. `MonthNum` — сезонность (ноябрь/декабрь)
